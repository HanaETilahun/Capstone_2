# Capstone_2

This project analyzes sales performance data for the South sales territory.

The analysis will focus on:
- Revenue trends
- Monthly sales performance
- Product category performance
- Store comparisons
- Recommendations for future sales growth

Territory being analyzed:
- Florida
- Texas
- South Carolina

Tools Used:
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook
- GitHub
